What runs here

Everything except the parts that need an operating system. wool, flock, ram, meadow and lamb work fully. pasture and shepherd load, but report a clear error when they are asked for a file or a subprocess, there is neither in a browser tab.

Loops that never end

Your program runs in a worker with a five-second limit, so while true { } costs you a click rather than the tab. If you hit it, the output pane says so.

Keyboard. Ctrl+Enter (or ⌘+Enter) runs. Tab inserts four spaces instead of leaving the editor. / focuses search on the documentation pages.

Ready for the real thing? Install Baa, it needs Node 22.18 or newer and has no runtime dependencies. Or read the language tour, which covers everything in about fifteen minutes.
